About the Game

Place yourself in the position of an experienced Computer Technician named Adam, tasked with fixing the world's most important computer in this highly entertaining online cybersecurity game! As Adam clicks on the wrong link, his computer faces a wide array of online malware infections. Move swiftly to identify phishing attempts and put an end to any malicious pop-ups and viruses infecting the computer. Prepare yourself for real-life cyber dangers by attempting to break your high score. Will you manage to get rid of all the infections, or has Adam's computer met its end?

Game Objective

Find safe files and stay away from dangerous files. Complete all system safety operations to save Adam's computer.

Loop of Gameplay:

• Click files to view them

• Choose to open, delete, protect, or cloud a file

• Close pop-ups safely

• Finish all tasks to save the system

• Unsafe actions will result in glitches, warnings, or pop-ups

• Use the System Recovery window to restore the system

User Guide

Controls

Left Clicking: opens files, makes actions, closes pop-ups, and interacts with windows.

Keys N / O (used only in the scam-credits section): Key N only works once all tasks are complete. Key O can only be pressed once all tasks have been completed.

Dangerous Programs and Files

• Corrupt.exe - dangerous, launches the glitch sequence

• BeanCola Adware - causes pop-ups

• Phishing pop-ups - fake prizes, always press the red X button

• Private_Info.txt - protect it for extra score points

• Harmless files - don't delete these

System Recovery (New Feature!)

The trash bin window contains two files. One is a genuine system file, the other is a virus imitating it. Select the correct file to restore the system - a wrong selection triggers a warning or glitch, while the right choice brings you closer to the win condition.

Winning & Losing Conditions

Win: Complete all tasks, including the System Recovery feature, to reach the "System Restored" ending.

Lose: Unsafe actions cause the system to crash.

What You'll Learn

Through this game, players learn to make sound judgment calls around computer safety. Every file and pop-up is modelled on real dangers found in modern computing - virus infections, phishing, and adware. Along the way, players practise recognising safe files, protecting private information, avoiding scams, and removing harmful software, using in-game features like the password manager, phishing pop-ups, and the trash bin.
